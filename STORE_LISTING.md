### Detailed Description (Overview Tab)

Copy and paste the formatted text below directly into the Chrome Web Store description field:

```text
📌 Sticky Notes for Any Webpage — Pin, drag, and organize colorful floating notes and interactive checklists right where you browse!

Whether you are conducting web research, organizing your daily tasks, drafting ideas, or leaving quick reminders on your favorite websites, NoteSticky keeps your thoughts anchored directly to any domain.

---

🌟 KEY FEATURES AT A GLANCE

📝 On-Page Sticky Notes
• Pin Anywhere: Place colorful sticky notes directly onto any webpage or domain.
• Complete Style Isolation: Built with open Shadow DOM so host webpage styles (Tailwind, Bootstrap, resets) never distort your notes, and your notes never alter website layouts.
• Smooth Dragging & Resizing: Seamlessly reposition notes with header dragging and resize with responsive pointer capture.
• 7 Vibrant Themes: High-contrast Canary Yellow, Fresh Mint, Blush Coral, Dream Lavender, Ocean Sky, Sunset Peach, and Dark Slate (WCAG AA compliant).
• Minimize & Collapse: Tidy up your browsing space by collapsing notes into compact title chips.

☑️ Interactive Checklist & Todo Mode
• 1-Click Conversion: Instantly convert any text note into an interactive checklist with checkboxes and strike-through completion.
• Real-time Progress: View completed vs pending items at a glance with built-in progress bars.

🎛️ Unified Workspace Dashboard
• Global Notes Manager: View, search, and manage all your notes across all websites in one clean popup dashboard.
• Domain Scoping: Notes persist across all subpages, query parameters, and paths on the same domain.
• Instant Search: Filter notes in real time by keywords, domain name, or color tags.
• Jump to Note (🚀): 1-click navigation automatically opens the page and highlights the sticky note with a pulsing gold indicator.
• Independent Toolbar Toggle: Create and manage notes in your workspace even when on-page floating toolbars are turned off.

⌨️ Keyboard Shortcuts & Context Menus
• Alt+Shift+W (Mac: MacCtrl+Shift+W): Instantly toggle the NoteSticky Workspace dashboard from any tab.
• Alt+Shift+N (Mac: MacCtrl+Shift+N): Create a new sticky note on the current page.
• Alt+Shift+H (Mac: MacCtrl+Shift+H): Toggle visibility of on-page sticky notes.
• Right-Click Menu: Highlight text and select "Create Sticky Note from selection" to capture information instantly.

🔒 100% Private & Offline
• Zero Remote Tracking: All data stays strictly on your machine in chrome.storage.local.
• No Tracking & No Telemetry: We do not collect, monitor, or sell any user information or browsing activity.
• JSON Backup & Restore: 1-click export and import of your entire note library anytime.

---

🚀 HOW TO USE NOTESTICKY

1. Click the "Add to Chrome" button above and pin NoteSticky to your extensions toolbar.
2. Visit any website and press Alt+Shift+N or click the floating "+" button to create your first sticky note.
3. Type notes, convert to checklists, change colors, or drag them anywhere on your screen.
4. Press Alt+Shift+W or click the extension icon to manage all your notes in the central dashboard.

---

💡 PERMISSIONS TRANSPARENCY
NoteSticky only requests permissions essential to its core features:
• storage: Saves your notes and settings locally on your computer.
• activeTab: Interacts with the active webpage only when you create or edit notes.
• contextMenus: Enables convenient right-click options to create sticky notes from selected text.

Need help or want to suggest a feature? Visit our official GitHub repository:
https://github.com/itsSkyCodes/NoteSticky
```

## 2. 🛡️ Privacy & Compliance Tab (Crucial for "Featured" Badge)

Google's review team awards the **Featured Badge** only to extensions with a clean privacy declaration and strict single-purpose adherence:

### Single Purpose Description
```text
NoteSticky provides an on-page sticky note and checklist widget that allows users to create, organize, and manage persistent personal notes directly on webpages and within a companion popup dashboard.
```

### Permission Justifications
* **`storage`**:
  * *Justification*: "Required to locally store the user's sticky notes, checklist items, screen position coordinates, color preferences, and workspace settings on their device."
* **`activeTab`**:
  * *Justification*: "Required to inject and position the sticky note overlay and floating toolbar onto the active webpage when requested by the user."
* **`contextMenus`**:
  * *Justification*: "Required to allow users to right-click selected webpage text and instantly create a sticky note from that selection."

### Data Usage Declarations
* Check: **"Does not collect or use personal data."**
* Check: **"I certify that my extension adheres to the Chrome Web Store Developer Program Policies."**
* Privacy Policy URL: `https://github.com/itsSkyCodes/NoteSticky/blob/main/PRIVACY_POLICY.md`
