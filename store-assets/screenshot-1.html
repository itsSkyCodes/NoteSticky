Using Shadow DOM for Style Encapsulation

Updated Today • 6 min read • Reference Architecture

Shadow DOM allows hidden DOM trees to be attached to elements in the regular DOM tree — this shadow DOM tree starts with a shadow root, underneath which can be attached any element, in the same way as the normal DOM.

const host = document.createElement('div');
const shadow = host.attachShadow({ mode: 'open' });
// Notes rendered here remain immune to page stylesheet rules!

Because CSS scoped within a shadow root doesn't bleed out into host pages, third-party browser extensions can guarantee predictable UI rendering across every website.
